# Входной контроль — наглядная нормализация данных

Проект демонстрирует полный путь данных:

```text
Ненормализованная SQLite БД
        ↓
Нормализованная PostgreSQL БД
        ↓
CSV и XLSX отчёты
```

Предметная область — книжный магазин.

## Цель работы

Программа показывает:

1. Как данные могут храниться в одной ненормализованной таблице.
2. Как эти же данные переносятся в нормализованную PostgreSQL БД.
3. Чем структура нормализованной БД отличается от ненормализованной.
4. Как из PostgreSQL формируются аналитические отчёты.
5. Как отдельное Python-приложение создаёт Excel-файлы.

## Ненормализованная БД

Исходная SQLite БД состоит из одного файла:

```text
data/source_bookstore.db
```

В ней есть одна таблица:

```text
sales_flat
```

В каждой строке этой таблицы одновременно хранятся:

- Номер и дата продажи
- Покупатель и телефон
- Сотрудник
- ISBN и название книги
- Жанр
- Автор
- Количество
- Цена

Из-за этого одинаковые сведения о книгах, авторах, жанрах и сотрудниках повторяются во многих строках.

## Нормализованная БД

PostgreSQL БД содержит семь таблиц:

```text
customers
employees
genres
authors
books
book_authors
sales
```

Связи:

```text
genres → books
```

Это связь один-ко-многим: один жанр может включать много книг.

```text
books ↔ authors
```

Это связь многие-ко-многим, реализованная через таблицу:

```text
book_authors
```

В таблице `sales` хранятся только реквизиты продажи и идентификаторы связанных объектов:

```text
customer_id
employee_id
book_id
```

Поэтому ФИО покупателя, сотрудника, книга, автор и жанр не копируются в каждую новую продажу.

## Аналитические отчёты

### Лучший сотрудник

Лучший сотрудник определяется по максимальной суммарной выручке:

```text
Количество × Цена = Сумма продажи
```

Затем все суммы продаж каждого сотрудника складываются.

### Крупнейшая продажа дня

Для каждой даты выбирается продажа с максимальной суммой:

```text
Количество × Цена
```

В отчёт попадают:

- Дата
- Номер продажи
- Покупатель
- Телефон покупателя
- Сотрудник
- Книга
- Количество
- Цена
- Итоговая сумма

## Отдельное приложение Excel

Основное приложение подготавливает данные и сохраняет CSV.

Затем оно запускает отдельный скрипт:

```text
scripts/render_report.py
```

Этот скрипт:

1. Читает CSV.
2. Создаёт Excel-файл XLSX.
3. Добавляет заголовок.
4. Оформляет шапку таблицы.
5. Добавляет фильтры.
6. Настраивает ширину колонок.
7. Форматирует денежные поля в рублях.
8. Сохраняет готовый Excel-файл.
