# Схема данных и EKNF

## Ненормализованная SQLite БД
Таблица `sales_flat` содержит все поля продажи в одной записи: номер и дату продажи, покупателя, телефон, сотрудника, ISBN, название книги, жанр, автора, количество и цену. Это намеренно денормализованное представление для импорта.

## Нормализованная PostgreSQL БД

| Таблица | Первичный ключ | Назначение |
|---|---|---|
| `customers` | `customer_id` | Покупатели; телефон уникален |
| `employees` | `employee_id` | Сотрудники-продавцы |
| `genres` | `genre_id` | Справочник жанров |
| `authors` | `author_id` | Справочник авторов |
| `books` | `book_id` | Книги; ISBN уникален |
| `book_authors` | `(book_id, author_id)` | Связь книг и авторов |
| `sales` | `sale_id` | Факты продаж; номер продажи уникален |

Каждая таблица имеет ключ, а неключевые атрибуты описывают только идентифицируемую ключом сущность; повторяющихся групп нет. Поэтому структура соответствует нормальной форме элементарных ключей в рамках требований задания.

## Связи
- **1:M:** `genres` → `books`; также `customers` → `sales`, `employees` → `sales`, `books` → `sales`.
- **M:M:** `books` ↔ `authors` через `book_authors`.

## Сохранность значений
Импортер переносит даты, ISBN, названия, ФИО, телефоны, числа и цены из `sales_flat` без изменения бизнес-значений. Нормализация разделяет их между сущностями и заменяет повторяющиеся естественные значения внешними ключами.
